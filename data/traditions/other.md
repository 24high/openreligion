# Sonstiges

Beispiele: Buddhismus, Jainismus, Daoismus, animistische Traditionen, säkularer
Humanismus, Agnostizismus, symbolischer Satanismus.

„Sonstiges“ ist eine Sammelkategorie, keine Wertung. Wächst eine Gruppe stark,
kann sie eine eigene Kategorie werden (über einen Konsensvorschlag zur Taxonomie).
